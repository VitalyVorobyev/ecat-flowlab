API reference

One entry per workspace crate, in dependency order. How the crates fit together is in the book's workspace overview.

  • ecat-wire Zero-copy EtherCAT frame, datagram and mailbox codec: parse and encode, no I/O.
  • flowlab-core Units, provenance and the report envelope shared by every result.
  • flowlab-capture pcap/pcapng reader and writer, and the indexed EtherCAT trace.
  • flowlab-analysis Capture analysis: cyclic streams, timing, working counters, load, stations, mailbox.
  • flowlab-synth Deterministic synthetic captures with known ground truth.
  • flowlab-sim Discrete-event simulator of master, link, ESC and PDI, emitting real frames.
  • flowlab-devices ESI and ENI readers, ENI writer and the bus-budget planner.
  • flowlab-study Parameter studies: sweeps, constraints, Pareto frontier, calibration.
  • flowlab-server Local HTTP API and static host for the UI.
  • flowlab-cli The flowlab command line.
