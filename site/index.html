EtherCAT analysis workbench · Rust + React · MIT OR Apache-2.0

See what an EtherCAT segment is doing, and what it could do.

FlowLab reads pcap and pcapng captures of a running segment and explains the cycle, working counters, bus load, state machines and mailbox conversations. It simulates segments that do not exist yet, through the same decoder and analysis, so measured and simulated traffic compare view for view.

Try it on a laptop

No EtherCAT hardware, network adapter, root or libpcap needed. Generate a synthetic capture with known faults, analyse it, and open the workbench.

measured
a capture recorded from a real network
simulated
produced by the discrete-event simulator
synthetic
generated with exact ground truth, to test the analysis

Every result carries one of these labels; they are never combined into one number. 

git clone https://github.com/VitalyVorobyev/ecat-flowlab
cd ecat-flowlab
cargo run -p flowlab-cli -- synth configs/synth/demo.json \
    -o results/demo.pcapng
cargo run -p flowlab-cli -- analyze results/demo.pcapng
(cd ui && bun install && bun run build)
cargo run -p flowlab-cli -- serve results/demo.pcapng
# open http://127.0.0.1:7878
